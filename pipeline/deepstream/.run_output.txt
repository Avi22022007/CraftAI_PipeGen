  From any machine that has the mosquitto clients installed:
      mosquitto_sub -h localhost -p 1883 -t 'hazard/alerts' -v

  To USE it, subscribe to that topic from your own program. One
  JSON message per frame: frame number, camera id, timestamp, and
  a list of objects — each with a label, a tracking id that
  follows it between frames, a confidence and a bounding box.

  Change the broker without rebuilding:
      MQTT_HOST=10.0.0.9 ./run.sh
